# Darren Robson — personal hub

The personal site of Darren Robson, Data Reporting Specialist & Web Developer. It collects my CV, certifications, web design projects and contact details on one page.

**Live:** https://darrenrosbon.github.io/DarrenRobsonHub/

## Built with

Hand-coded HTML, CSS and JavaScript. No frameworks, no build step, no trackers.

- Light and dark themes. The site follows the device setting, and a toggle remembers your choice.
- Responsive from 320 px up, with a full-screen menu on phones and tablets.
- Accessible: skip link, visible focus rings, keyboard-friendly menu, screen-reader announcements, and respect for reduced motion and reduced transparency.
- Fast: images are sized for each screen, nothing blocks the page from rendering, and the layout doesn't shift while loading.
- Cards grow into their detail pages with cross-document view transitions, and the next page is prerendered on hover.
- The hero photo flies into the nav on scroll, driven by a CSS scroll timeline.
- Scores 100 in every Lighthouse category (performance, accessibility, best practices, SEO), and CI enforces it.

## Project structure

```
index.html            the page
404.html              "page not found" page (GitHub Pages serves it for missing URLs)
certificates/         one viewer page per certificate, with a preview and a download button
work/                 one case study page per project
cv/                   the CV as a web page, with a print stylesheet for A4
styles.css            all styles, including theme tokens at the top
script.js             home page only: menu, scroll spy, gallery arrows, copy-email, hero photo flight, counters
common.js             every page: appearance switch, toast messages, back-to-top button
manifest.webmanifest  app name and icons for home-screen installs
tools/build_pages.py  generates the certificate, project, CV and 404 pages and their share images
robots.txt, sitemap.xml
assets/
  cv/                 CV (PDF)
  certs/              certificates (personal ID numbers removed)
    previews/         WebP previews of each certificate at 700 and 1400 px
  projects/           project screenshots at 480, 640 and 960 px
  icons/              favicon and app icons
  og/                 share images for each detail page (generated)
```

## Run locally

Any static file server works, for example:

```
python -m http.server 8000
```

Then open http://localhost:8000.

## Quality checks

Every push and pull request runs three checks (see `.github/workflows/ci.yml`):

1. **HTML validation**: `html-validate` with its recommended rules.
2. **Broken link check**: `lychee` checks every link on the page.
3. **Lighthouse CI**: fails the build if accessibility, best practices or SEO drop below 100, or performance drops below 95.

Pushes to `main` deploy to GitHub Pages (`.github/workflows/pages.yml`).

## Changing the address

The site address `https://darrenrosbon.github.io/DarrenRobsonHub/` appears in `index.html` (canonical, Open Graph and structured data), `robots.txt`, `sitemap.xml`, and as `/DarrenRobsonHub/` in `404.html`. If the repository is renamed or a custom domain is added, replace it in all of those files.

## Editing the detail pages

The certificate, project, CV and 404 pages are generated by `tools/build_pages.py`, which holds their content (it needs Python with Pillow and PyMuPDF, and Windows fonts for the share images): `python tools/build_pages.py`.
Edit the text there and rerun it, rather than editing the HTML files directly.
